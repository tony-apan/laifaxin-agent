来发信 Agent 接入

开放服务

来发信开放服务，是为 AI Agent 打造的来发信操作通道。装好之后，你的 Agent 就能直接在你的来发信账号里搜客户、管联系人、处理邮件和营销任务——你只管下指令、看结果。

Agent 一键接入

将以下提示词发送到你的 Agent 对话窗口，根据引导完成安装和授权。

请阅读 https://agent.laifa.xin/doc/skill-setup.md 文档，按照步骤为我安装并配置来发信 Skill。
已复制，去粘贴给你的 Agent 吧

接入后能做什么

① 搜客户AI 数据库、领英、域名搜索，筛选后一键保存到联系人
② 管客户联系人与公司、标签、跟进记录、导入导出
③ 处理邮件收件箱阅读、写信、回复转发、定时发送与追踪
④ 做营销邮件群发、智能跟进计划、营销报告

授权采用网页设备授权：Agent 不接触你的密码，凭据只保存在你本机，可随时在来发信网页端「个人设置 → 安全设置 → 已授权应用」撤销。

手动下载

也可以先下载 Skill 包，再让 Agent 从本机文件安装。当前版本 v6.1.28，需要 Python 3.10+ 与能执行本机脚本的 Agent 宿主。

技术用户也可以用 skills CLI 一键安装（自动发现、校验并链接到各 Agent）：

npx skills add https://agent.laifa.xin -g -y
