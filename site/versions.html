版本与更新

这里记录每个公开发布的版本更新了什么。想知道自己装的是不是最新，翻到下面有查看方法。

v6.1.28 当前版本 2026 年 11 月发布
  • 首个公开发布版本。覆盖来发信 417 个业务接口：找客户、管客户、收发邮件、批量开发与跟进、账户费用查询，都能交给 AI 助手办。
  • 官方网页授权。在来发信网页上登录确认即可连接，密码不经过 AI 助手；凭据只存你的电脑，30 天有效，随时可撤销。
  • 一对一发送。给多位客户发信时每人分别发送、互不可见；支持定时发送，预约后还能改期或取消。
  • 打开追踪。信发出后，能看到客户有没有打开，方便判断什么时候再跟进。
  • 群发与智能跟进。按计划批量发送、自动跟进，执行完出一份结果报告，失败的原因也写明。
  • 装好即用。零额外依赖，只需要 Python 3.10 以上；全部源码在 GitHub 公开可查。
如 何 更 新
01

把首页那句话再发一次

回到本站首页，复制接入提示词发给你的 AI 助手，它会把技能更新到最新版，原有授权一般不用重做。

02

等它确认

更新完成后，让助手报一下当前版本号，跟本页「当前版本」对得上就是最新。

03

也可以手动下载

从 GitHub 的 Release 页下载最新版 zip，替换掉原来的技能文件夹，效果一样。

查 看 自 己 的 版 本

直接问你的 AI 助手：「我装的来发信 Skill 是什么版本？」它会告诉你。也可以打开技能文件夹里的 SKILL.md，第一部分就写着版本号。

每个版本的源码与完整说明都在 GitHub Release 页公开，可以自行查阅或审查。
